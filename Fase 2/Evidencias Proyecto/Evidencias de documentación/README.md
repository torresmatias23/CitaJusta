# Evidencias de documentación

## Propósito

Reunir los documentos técnicos exigidos para acreditar el diseño y desarrollo de CitaJusta, conservando versiones históricas y versiones actualizadas cuando cambie el estado real del proyecto.

## Estado al 04-10-2026

- Documento Base y Justificación se conservan como evidencia histórica existente.
- Requisitos Funcionales v0.1 se conserva; v0.2 incorpora el estado actualizado y RF-039 a RF-043.
- Arquitectura de Software v0.1 y Arquitectura APIs v0.1 se conservan; las versiones v0.2 reflejan Web, Desktop, backend real y la planificación de integraciones externas.
- Stack Tecnológico v0.1 se conserva; v0.2 sincroniza tecnologías efectivamente implementadas, Prisma 7.10.0, Desktop, Sprint 8 y Docker/Compose como pendiente de Sprint 9.
- Product Backlog, Épicas/Historias y Release Plan se mantienen en `Scrum/` como documentos vivos de planificación.

## Cambio de alcance del 15-10-2026

HU-043 / RF-043 (WhatsApp Cloud API) se descarta definitivamente del entregable por restricciones empresariales de Meta para el contexto académico. El estado al 04-10-2026 anterior es histórico. Los DOCX/XLSX se mantienen intactos y requieren una actualización versionada del alcance; no marcar HU-043 como implementada ni eliminar evidencias de sprints cerrados. Referencias y acciones por archivo en el [inventario documental](../../../docs/capstone/DOCUMENT_INVENTORY.md#retiro-hu-043-del-alcance-entregable).

## Pendientes de cierre

Continúan pendientes los artefactos académicos que todavía no tienen evidencia final consolidada, entre ellos modelo ER formal, UML requeridos, requisitos no funcionales medibles, manual técnico, pruebas de rendimiento/seguridad dedicadas, Docker/Compose, OpenAPI y presentación final.
